🎮 أزرار المغامرة (البابا / الماما يضغطون)
نص القراءة لليوم
الكلمة الصعبة (الوحش)
💡 اقتراح تدرّج الأيام
  1. اليوم 1: سطر واحد فقط
  2. اليوم 2: سطر + تحديد كلمة صعبة
  3. اليوم 3: سطر + مكافأة التصحيح الذاتي
  4. اليوم 4: سطران
  5. اليوم 5: سطران + وحش كلمة صعبة
  6. اليوم 6: سطران بقراءة هادئة
  7. اليوم 7: يوم الزعيم — سطران + 3 كلمات صعبة 🏆
✅ محاولة ثم خطأ = لا يخسر قلبًا
✅ طلب المساعدة مقبول (−1 نقطة فقط، بدون خسارة قلب)
💨 التخمين / الاستعجال فقط = −1 قلب
